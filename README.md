# Eduvos AI Study Prompt Generator

A lightweight, responsive web application designed for Eduvos IT students to transform course notes and module content into optimized prompts for Claude.

## 🚀 Live Demo
[View Live Application](https://kutlomotsewabone68-beep.github.io/eduvos-study-prompt-tool/)

## 🛠️ Tech Stack
* **HTML5:** Page structure and semantic form controls.
* **CSS3:** Custom styling and responsive design layout.
* **JavaScript (Vanilla):** Dynamic prompt formatting and clipboard integration.

## 📌 Features
* **Task Selection:** Switch between note simplification, practice quiz generation, and code concept explanations.
* **Custom Inputs:** Input specific module names and raw study notes.
* **Instant Formatting:** Automatically injects inputs into structured system prompts.
* **One-Click Copy:** Easily copy formatted prompts directly to your clipboard for use in Claude.
